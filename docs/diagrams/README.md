# Diagrams

Architecture and workflow diagrams for this repo, as Excalidraw files.

## Workflow

1. Close the diagram tab in Obsidian before regenerating (the plugin can overwrite agent edits).
2. Agent builds diagrams with the `excalidraw-diagram` skill into this folder.
3. Prefer **`.excalidraw.md`** for the [Obsidian Excalidraw plugin](https://github.com/zsviczian/obsidian-excalidraw-plugin).
4. Open in Excalidraw view (⋯ → Excalidraw View if you see markdown).

There is **no Excalidraw MCP** — diagrams are repo files.

## Open in Obsidian

Open the **DSKT-setup root** (or this `docs/diagrams` folder) as a vault. Install/enable **Excalidraw** under Community plugins for that vault.

```bash
./scripts/open-diagram.sh docs/diagrams/dskt-system-context.excalidraw.md
```
